✨ First, Let’s Understand the Basics

🔰

What Is a Logo?

A logo is a visual symbol that represents a project. It helps people recognise and remember it. A good logo is simple, original and meaningful. Choose shapes, symbols and colours that match your project.

Think: one memorable symbol
🖼️

What Is a Poster?

A poster introduces a project, event or idea with a clear title, short text and visuals. It should catch attention quickly. Use readable text, a balanced layout and images that support your message.

Think: one clear message
💬

What Is a Slogan?

A slogan is a short, catchy phrase that expresses the main message of a project. It should be easy to say, easy to remember and connected to the project’s purpose.

Think: a few powerful words
